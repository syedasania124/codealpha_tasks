# FAQ Chatbot

## 📌 Project Description

This project is an AI-based FAQ Chatbot developed using Python.  
The chatbot processes user questions and provides suitable answers from a predefined FAQ knowledge base.

It uses Natural Language Processing (NLP) techniques and TF-IDF based text processing to support question matching and understanding.

## ✨ Features

- Interactive graphical user interface using Tkinter
- FAQ-based question answering
- NLP text preprocessing
- Stemming using NLTK
- TF-IDF text vectorization
- Handles common spelling mistakes
- Rejects unrelated questions
- Quick question buttons
- Clear chat functionality
- Enter key support for sending messages

## 🛠️ Technologies Used

- Python
- Tkinter
- NLTK
- Scikit-learn
- TF-IDF
- Cosine Similarity
