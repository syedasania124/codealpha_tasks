# 🌐 AI Language Translation Tool

An AI-based Language Translation Tool developed using Python and Tkinter. 
The application uses an online Translation API to translate text between multiple languages.

## ✨ Features

- 🌍 Translate text between multiple languages
- 🔄 Swap source and target languages
- 📋 Copy translated text
- 🧹 Clear input and output
- 📊 Character counter
- 🎨 Professional dark and maroon GUI
- 🌐 Online API-based translation
- ⚡ Simple and easy-to-use interface

## 🛠️ Technologies Used

- Python
- Tkinter
- Requests
- MyMemory Translation API

## 🌎 Supported Languages

The application currently supports:

- English
- Urdu
- Hindi
- Arabic
- French
- Spanish
- German
- Italian
- Portuguese
- Russian
- Chinese
- Japanese
- Korean
- Turkish
- Dutch
